# Script — Traduzione alternativa

**Campo checklist:** `alt`
**Cartella canonica:** `prompt/CREA STORIA/`
**Tipo:** prompt LLM

Questo file e' il punto di ingresso per un'altra AI: leggilo (e gli allegati citati) per generare o aggiornare il campo.

## Come eseguire / usare

Puo' partire dall'export 'Vedi frasi…'.

---

## Obiettivo
Per ogni frase, una seconda resa naturale in lingua obiettivo (campo `alt`), diversa da `target` ma equivalente.

## Prompt
Ti do le coppie known/target. Per ciascuna riga scrivi UNA alternativa in lingua obiettivo, stesso significato, registro naturale, non una traduzione parola-per-parola diversa solo di sinonimi inutili.

Formato output (ripeti per ogni frase):

[SIGLA]-alternativa: ...

Esempio se target=EN:
EN-alternativa: ...
