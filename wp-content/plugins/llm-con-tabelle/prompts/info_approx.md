# Info — Pronuncia approssimata

## Script / prompt (cartella canonica)
File da usare: `prompt/CREA STORIA/script_approx.md`

Copia anche in: `wp-content/plugins/llm-con-tabelle/prompts/script_approx.md`

Un'altra AI deve aprire **quel** file `script_*.md` (e gli script PHP `script-*.php` citati dentro, se presenti nella stessa cartella) per generare o aggiornare questo campo. Non cercare script sparsi altrove finche' non indicato li'.

## Cos’è
Riscrittura “come si legge” con ortografia della lingua nota (aiuto per principianti), per-frase.

## Chi lo crea di solito
- **AI** insieme al pacchetto pronuncia, o manualmente.
- Cursor può generarla dalle frasi target.

## Prompt
Nessun prompt checklist dedicato al momento.

## Cosa deve sapere un’altra AI
- Deve essere leggibile da chi parla la lingua known.
- Non sostituisce IPA; è un ponte didattico.
