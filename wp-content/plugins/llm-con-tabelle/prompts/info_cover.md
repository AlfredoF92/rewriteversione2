# Info — Copertina

## Script / prompt (cartella canonica)
File da usare: `prompt/CREA STORIA/script_cover.md`

Copia anche in: `wp-content/plugins/llm-con-tabelle/prompts/script_cover.md`

Un'altra AI deve aprire **quel** file `script_*.md` (e gli script PHP `script-*.php` citati dentro, se presenti nella stessa cartella) per generare o aggiornare questo campo. Non cercare script sparsi altrove finche' non indicato li'.

## Cos’è
Immagine in evidenza (featured image) della storia: usata in card, popup, magazine, calendario uscite.

## Chi lo crea di solito
- **Utente / designer**: genera o sceglie l’immagine e la carica come featured image in WP.
- Cursor può guidare prompt di generazione immagine, ma l’upload è umano (o script di import media).

## Prompt
Nessun prompt checklist. Eventuali prompt immagine vivono fuori dalla checklist.

## Cosa deve sapere un’altra AI
- Senza copertina la storia appare “vuota” in home/caroselli.
- Formato consigliato: JPEG/WebP, soggetto chiaro, leggibile in thumbnail.
