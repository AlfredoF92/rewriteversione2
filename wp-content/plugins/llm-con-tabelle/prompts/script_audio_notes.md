# Script — Audio delle note

**Campo checklist:** `audio_notes`
**Cartella canonica:** `prompt/CREA STORIA/`
**Tipo:** CLI PHP

Questo file e' il punto di ingresso per un'altra AI: leggilo (e gli allegati citati) per generare o aggiornare il campo.

## Come eseguire / usare

CLI only.

---

## Script eseguibile (copia anche in questa cartella)
- `script-genera-audio-note.php` (riferimento operativo: `wp-content/plugins/llm-con-tabelle/scripts/` e copia in `prompt/CREA STORIA/`)

## Comando
```
C:\xampp\php\php.exe "wp-content/plugins/llm-con-tabelle/scripts/script-genera-audio-note.php" --story=ID [--count=N] [--offset=0] [--force]
```

Prerequisito: note testo gia' compilate.
