# Script — Lingue nota + obiettivo

**Campo checklist:** `langs`
**Cartella canonica:** `prompt/CREA STORIA/`
**Tipo:** manuale (meta WP)

Questo file e' il punto di ingresso per un'altra AI: leggilo (e gli allegati citati) per generare o aggiornare il campo.

## Come eseguire / usare

Nessun prompt LLM obbligatorio: metadato obbligatorio in admin.

---

## Obiettivo
Impostare `_llm_known_lang` e `_llm_target_lang` sulla storia.

## Chi lo fa
Utente in admin storia. L'AI puo' solo proporre la coppia; non pubblicare meta senza conferma.

## Regole
- Codici validi del progetto (it, en, es, pl, …)
- known != target
