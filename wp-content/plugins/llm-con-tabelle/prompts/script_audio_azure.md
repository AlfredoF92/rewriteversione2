# Script — Audio Azure M+F

**Campo checklist:** `audio_azure`
**Cartella canonica:** `prompt/CREA STORIA/`
**Tipo:** pipeline Azure

Questo file e' il punto di ingresso per un'altra AI: leggilo (e gli allegati citati) per generare o aggiornare il campo.

## Come eseguire / usare

Dipende da credenziali Azure/config STT del sito.

---

## Obiettivo
Traccia completezza audio canale Azure (M+F) per frase.

## Come generare
Usa gli strumenti TTS Azure del plugin (`LLM_STT` / `LLM_Phrase_TTS`) dall'admin storia, oppure batch locali (_tmp_*_azure) se presenti nel workflow dell'utente.

Checklist ok quando M e F sono presenti per tutte le frasi.
