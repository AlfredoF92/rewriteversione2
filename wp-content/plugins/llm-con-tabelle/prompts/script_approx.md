# Script — Pronuncia approssimata

**Campo checklist:** `approx`
**Cartella canonica:** `prompt/CREA STORIA/`
**Tipo:** prompt LLM

Questo file e' il punto di ingresso per un'altra AI: leggilo (e gli allegati citati) per generare o aggiornare il campo.

## Come eseguire / usare

Spesso insieme a pronunciation/ipa.

---

## Obiettivo
Riscrivere come si legge con ortografia della lingua nota (campo `approx`).

## Prompt
Per ogni frase target, scrivi una lettura approssimata pensata per chi parla solo la lingua known. Usa sillabe/ortografia known, non IPA. Una riga per frase.
