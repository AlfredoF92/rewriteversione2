# Script — IPA

**Campo checklist:** `ipa`
**Cartella canonica:** `prompt/CREA STORIA/`
**Tipo:** prompt LLM

Questo file e' il punto di ingresso per un'altra AI: leggilo (e gli allegati citati) per generare o aggiornare il campo.

## Come eseguire / usare

Incolla in admin / repository per-frase.

---

## Obiettivo
Trascrizione IPA per ogni frase (o segmenti rilevanti), campo `ipa`.

## Prompt
Data la frase in lingua obiettivo, produci trascrizione IPA standard di quella lingua. Una riga per frase, allineata all'ordine. Niente simboli non IPA. Se la frase e' lunga, trascrivi l'intera frase.
