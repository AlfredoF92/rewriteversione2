# Script — Copertina

**Campo checklist:** `cover`
**Cartella canonica:** `prompt/CREA STORIA/`
**Tipo:** prompt immagine + upload umano

Questo file e' il punto di ingresso per un'altra AI: leggilo (e gli allegati citati) per generare o aggiornare il campo.

## Come eseguire / usare

Nessun CLI: upload manuale (o script media esterno se esiste).

---

## Obiettivo
Featured image della storia.

## Prompt immagine (template)
Crea una copertina editoriale verticale/orizzontale adatta a thumbnail web, soggetto chiaro legato a: [TITOLO / PLOT]. Stile coerente col brand Lovrite, niente testo illeggibile, niente watermark.

## Dopo la generazione
Caricare come immagine in evidenza WP sulla storia `llm_story`.
