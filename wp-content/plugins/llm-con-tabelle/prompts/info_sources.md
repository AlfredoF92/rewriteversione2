# Info — Fonti

## Script / prompt (cartella canonica)
File da usare: `prompt/CREA STORIA/script_sources.md`

Copia anche in: `wp-content/plugins/llm-con-tabelle/prompts/script_sources.md`

Un'altra AI deve aprire **quel** file `script_*.md` (e gli script PHP `script-*.php` citati dentro, se presenti nella stessa cartella) per generare o aggiornare questo campo. Non cercare script sparsi altrove finche' non indicato li'.

## Cos’è
Elenco fonti / riferimenti della storia (URL, titoli, crediti canzone, ecc.).

## Chi lo crea di solito
- **Utente**: inserisce le fonti in admin.
- AI può suggerirle da un documento, ma la responsabilità legale/crediti è umana.

## Prompt
Nessuno in checklist.

## Cosa deve sapere un’altra AI
- Non inventare fonti.
- Per canzoni: artista, titolo, eventuale link ufficiale.
