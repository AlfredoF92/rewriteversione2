# Info — IPA

## Script / prompt (cartella canonica)
File da usare: `prompt/CREA STORIA/script_ipa.md`

Copia anche in: `wp-content/plugins/llm-con-tabelle/prompts/script_ipa.md`

Un'altra AI deve aprire **quel** file `script_*.md` (e gli script PHP `script-*.php` citati dentro, se presenti nella stessa cartella) per generare o aggiornare questo campo. Non cercare script sparsi altrove finche' non indicato li'.

## Cos’è
Trascrizione fonetica IPA della frase (o delle parti rilevanti), per-frase.

## Chi lo crea di solito
- **AI / tool fonetici**, a volte Cursor con istruzioni IPA.
- Spesso validato da chi conosce la lingua obiettivo.

## Prompt
Nessun prompt checklist dedicato al momento (candidabile in futuro).

## Cosa deve sapere un’altra AI
- Usare IPA standard della lingua target.
- Non inventare simboli non IPA.
- Allineare a `approx` se entrambi presenti.
