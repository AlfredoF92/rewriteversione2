# Campioni espressioni (campo unico `explanation`)

Campi admin: `category` | `phrase` | `explanation`

Formato tipico di `explanation`:

```
Si può tradurre come «…»: significa che …
Equivalente …: …
```

Esempio (IT→EN):

- phrase: It's a piece of cake
- explanation:
  Si può tradurre come «Un pezzo di torta»: significa che qualcosa è semplicissimo da fare.

  Equivalente italiano: Facile come bere un bicchiere d'acqua / È una passeggiata.

I dati completi sono in `seed-idiom-samples.php` (banche it→en, it→pl, pl→it).
